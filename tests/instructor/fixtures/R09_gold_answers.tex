\section*{Problem B2}\label{ans:B2}
\begin{answer}
An observation records either the returned positioned AST, its nested scalar
spans and actual canonical interval vector with the lowered tree, or the
original failure position. Cursor observations include the unchanged input
and the precise old and final positions on success and failure. UTF8 byte
positions are not interchangeable with scalar positions.
Let $C$ be the original contract and $M$ the independently transcribed mirror.
Prove $C\Rightarrow M$ and $M\Rightarrow C$ on the same domain and observation
relation. This establishes equivalence relative to that mirror. It does not
show that either specification captures the intended grammar: a shared wrong
position or permissive always-error statement can satisfy both.
Compile the actual implementations and compare fixed cases before editing.
Include Unicode after a prefix, exact nested spans, overlapping/duplicate class
ranges, malformed/truncated counts and each cap boundary. Change a rejection
location to zero as a negative control: safety can survive while exact
observations differ. Mutant-kill parity must compare actual failing case IDs;
a parse failure is not a semantic rejection and an out-of-resource result is
not a counterexample. Literal success and meaning within the cap prevent an
always-error implementation from satisfying the complete frontend contract.
The fixed-copy representation has cost $1+n(b+1)$, and the optional-copy
representation has cost $1+(m-n)(b+3)$. Their outer concatenation adds one,
so total cost is $3+n(b+1)+(m-n)(b+3)=3+bm+n+3(m-n)$.
Check the fixed overhead against the cap first. For $m>0$, compare the child
cost with remaining space divided by $m$ before multiplying. A positive count
cannot hide an oversized child, but $m=0$ must bypass it and construct only the
constant three-node result. Compute the structural cost before expanded
allocation. The logical tree-node bound does not promise the same sharing,
stack use or peak heap consumption in both runtimes. Native gates, audits,
source snapshots, finite compiled agreement and measured actor outcomes
remain separate evidence; live actor work is deferred rather than inferred.
\end{answer}
