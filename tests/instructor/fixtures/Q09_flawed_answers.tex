\section*{Problem B1 (hand-calculation)}\label{ans:B1}
\begin{answer}
\textbf{(a)} \\
$p_0 q_0 = 0.3 \times 0.7 = 0.21$ \quad $p_0 q_0 / n = 0.21/40 = 0.00525$ \quad its
root $= 0.07246$ \\
$z_a + z_b = 1.96 + 0.8416 = 2.8016$ \quad $\delta_1 = 2.8016 \times 0.07246 = 0.2030$

\textbf{(b)} \\
$p_1 = 0.3 + 0.2030 = 0.5030$ \quad $\bar p = (0.3 + 0.5030)/2 = 0.4015$ \\
$\sqrt{2 \bar p \bar q} = \sqrt{2 \times 0.4015 \times 0.5985} = 0.6933$ \quad
$\sqrt{p_0 q_0 + p_1 q_1} = \sqrt{0.21 + 0.5030 \times 0.4970} = 0.6782$ \\
$n(\delta_1) = (1.96 \times 0.6933 + 0.8416 \times 0.6782)^2 / 0.2030^2 =
1.9296^2 / 0.04121 = 90.3$ \quad detectable at $n = 40$: no, it needs about 90
tasks per arm. \\
\texttt{fvh.stats.mde\_two\_proportions(40, 0.3)} $= 0.3073$ \quad $n$ at that
value: $(1.96 \times 0.7041 + 0.8416 \times 0.6697)^2 / 0.3073^2 = 3.7775/0.09444 =
40.0$, which checks.

\textbf{(c)} $n(0.10) = (1.96 \times 0.6745 + 0.8416 \times 0.6708)^2 / 0.01 =
1.8867^2/0.01 = 356$ tasks per arm. \\
What the pre-registration must say or change: with 40 tasks per arm the lab can
only detect a rise of about 31 points, so a 10-point rise is invisible. It must
state that MDE before the run and either claim only effects of that size or
move to about 356 tasks per arm, before any result is seen.

\textbf{(d)} The paired value: $0.3181$. \\
Why it is conservative: the formula plugs in the discordance rate two
independent arms would have, and arms run on the same tasks agree more often,
so they discord less and their real MDE is below this value.
\end{answer}
