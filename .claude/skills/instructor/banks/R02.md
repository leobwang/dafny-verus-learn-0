### PP1 — a marked concatenation boundary
**Isolates:** `quantifiers`, `anchoring`.

The second sequence begins with a marker. Find a boundary in the concatenation
whose prefix and suffix recover both inputs and whose character is the marker.

```dafny
module R02_ParallelBoundary {
  lemma MarkedJoinBoundary(a: seq<char>, b: seq<char>)
    requires |b| > 0 && b[0] == '#'
    ensures exists i :: 0 <= i < |a + b| && (a + b)[..i] == a && (a + b)[i..] == b && (a + b)[i] == '#'
}
```

verus! {
proof fn lemma_marked_join_boundary(a: Seq<char>, b: Seq<char>)

        && (a + b).subrange(i, (a + b).len() as int) == b && (a + b)[i] == '#',

}

### PP2 — search a labelled sprig
**Isolates:** `datatypes-and-match`, `termination-measure`, `spec-vs-exec`.

Implement a recursive search for a desired label. Its specification is given;
the executable routine must inspect the structure and preserve the contract.

```dafny
module R02_ParallelSprig {
  datatype Sprig = Bud(c: char) | Fork(a: Sprig, b: Sprig) | Coil(a: Sprig)
  ghost predicate SprigHas(r: Sprig, c: char)
    decreases r
  { match r case Bud(d) => d == c case Fork(a, b) => SprigHas(a, c) || SprigHas(b, c) case Coil(a) => SprigHas(a, c) }
  method SprigSeek(r: Sprig, c: char) returns (found: bool)
    ensures found == SprigHas(r, c)
    decreases r
  { assume false; }
}
```

```rust
use vstd::prelude::*;
verus! {
pub enum Sprig { Bud(char), Fork(Box<Sprig>, Box<Sprig>), Coil(Box<Sprig>), }
pub open spec fn sprig_has(r: Sprig, c: char) -> bool
    decreases r,
{ match r { Sprig::Bud(d) => d == c, Sprig::Fork(a, b) => sprig_has(*a, c) || sprig_has(*b, c), Sprig::Coil(a) => sprig_has(*a, c), } }
#[verifier::external_body]
fn sprig_seek(r: &Sprig, c: char) -> (found: bool)
    ensures found == sprig_has(*r, c),
    decreases r,
{ unimplemented!() }
}
```
