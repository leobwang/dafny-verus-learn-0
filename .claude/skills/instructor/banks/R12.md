### K4 [derive] — what a site must name
**viva:** yes · **tags:** `witnesses`, `contract-allowlist` · **backward-edge:** R04 (an existential and its witness)

The native lemmas are hint-site forms: the statement and the skeleton are frozen, and a site takes one expression or a few listed calls. For the `Cat` existential of `Matches`, what must a site name before the verifier can use the two hypotheses, and why does a true fact that names no split (for instance `|u + v| == |u| + |v|`) not help? Then, for an induction skeleton with a `calls` site, why is "call the lemma on something smaller" not yet an answer?

**Target insights.** An existential is proved at a witness, and the solver finds a witness only through a term of the trigger's shape: here slices of `u + v` at `|u|`, stated as equalities to the two words. A length fact is true and has no slice term in it. A `calls` site is an induction step only when its arguments are the ones the skeleton's split produced (the tail, the lowered bounds); a smaller but different argument proves a fact about a different word.

**Misconception → counter-move.** "Any true fact about the words helps": show the failing run with the length fact at the site. "Any recursive call is induction": ask which word the call's conclusion is about.

**Incomplete → narrow.** Name the obligation the verifier reports and the term it lacks. **Off-track → anchor.** Read the trigger of the existential in the given layer. **Correct → deepen.** Say how an engine proposing site text could be checked without trusting it.

### PP2 — parallel to R12.H2d and R12.H2v (a branch and an induction call)

Exactly `n` copies are at most `k >= n` copies. Two sites: the induction call on the tail and the `Alt` branch that holds.

```dafny
// R12_HINT_SITES: [{"name":"q1","identifiers":["Matches","Cat","CopiesUpTo","r","k","w","i"]},{"name":"q2","identifiers":["r","n","k","w","i"],"kind":"calls","callees":["CopiesInUpToR12"]}]
module R12_ParallelUpTo {
  import opened RG_A1_Re
  import opened RG_A3_Syntax

  // PP2: exactly n copies are at most k >= n copies. Fill sites q1, q2 and delete the assume.
  lemma CopiesInUpToR12(r: Re, n: nat, k: nat, w: seq<char>)
    requires n <= k && Matches(Copies(r, n), w)
    ensures Matches(CopiesUpTo(r, k), w)
    decreases n
  {
    assume false;
    if n == 0 {
      assert w == [];
      if k > 0 {
        assert Matches(Eps, w);
      }
    } else {
      var i :| 0 <= i <= |w| && Matches(r, w[..i]) && Matches(Copies(r, n - 1), w[i..]);
      /*R12_CALLS:q2*/
      assert w[..i] + w[i..] == w;
      assert /*R12_HINT:q1*/ true;
    }
  }
}
```

```rust
// R12_HINT_SITES: [{"name":"q1","identifiers":["matches","Re","Box","copies_up_to","r","k","w"]},{"name":"q2","identifiers":["r","n","k","w","i"],"kind":"calls","callees":["lemma_copies_in_up_to_r12"]}]
use vstd::prelude::*;
use rg_re_a1::*;
use rg_re_a3::*;

verus! {

// PP2: exactly n copies are at most k >= n copies. Fill sites q1, q2 and delete the assume.
proof fn lemma_copies_in_up_to_r12(r: Re, n: nat, k: nat, w: Seq<char>)
    requires
        n <= k,
        matches(copies(r, n), w),
    ensures
        matches(copies_up_to(r, k), w),
    decreases n,
{
    #[verifier::proof_note("PP2")] assume(false);  // HOLE: delete this line
    if n == 0 {
        assert(w.len() == 0);
        if k > 0 {
            assert(matches(Re::Eps, w));
        }
    } else {
        let i = choose|i: int|
            0 <= i <= w.len() && matches(r, #[trigger] w.subrange(0, i)) && matches(
                copies(r, (n - 1) as nat),
                w.subrange(i, w.len() as int),
            );
        /*R12_CALLS:q2*/
        assert(w.subrange(0, i) + w.subrange(i, w.len() as int) =~= w);
        assert(/*R12_HINT:q1*/ true);
    }
}

} // verus!
```

**Done =** `scripts/vcheck --module R12 <file>` prints `verified` with `0 holes, 0 errors`, in each language.

**Author-verified (2026-10-18, the course pins):** as shipped, each file verifies with exactly one hole (`hole assume R12_ParallelUpTo.CopiesInUpToR12`; `hole assume PP2`); with the hole deleted and both sites empty, each fails at the postcondition; filled, each verifies (Dafny 63 verified, Verus 1 verified, 0 holes).
