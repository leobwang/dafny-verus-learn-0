### PP2 — count two contributions per step
**Isolates:** a small recursive bridge and a decreasing argument.

Keep the definition fixed. Justify the recursive call and connect its
postcondition to the advertised arithmetic expression.
```dafny
module R05_ParallelCount {
  ghost function PairCountR05(n: nat): nat
    decreases n
  { if n == 0 then 0 else 2+PairCountR05(n-1) }
  lemma PairCountLinearR05(n: nat)
    ensures PairCountR05(n) == 2*n
    decreases n
}
```

```rust
use vstd::prelude::*;
verus! {
pub open spec fn pair_count_r05(n: nat) -> nat
    decreases n,
{ if n == 0 { 0 } else { 2+pair_count_r05((n-1) as nat) } }
proof fn lemma_pair_count_linear_r05(n: nat)
    ensures pair_count_r05(n) == 2*n,
    decreases n,
{ #[verifier::proof_note("parallel")] assume(false); }
}
```
