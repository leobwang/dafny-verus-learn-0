### PP1 — preserve a lower bound when appending
**Isolates:** `quantifiers`, `assert-by`.

Prove the universal postcondition for the original positions and appended
position; keep the bounds and given assumptions unchanged.

```dafny
module R04_ParallelBound {
  lemma AppendLowerBound(a: seq<int>,x: int,bound: int)
    requires forall i :: 0 <= i < |a| ==> a[i] >= bound
    requires x >= bound
    ensures forall i :: 0 <= i < |a+[x]| ==> (a+[x])[i] >= bound
}
```

```rust
use vstd::prelude::*;
verus! {
proof fn lemma_append_lower_bound(a: Seq<int>,x: int,bound: int)
    requires forall|i: int| 0 <= i < a.len() ==> #[trigger] a[i] >= bound,
        x >= bound,
    ensures forall|i: int| 0 <= i < a.push(x).len() ==> #[trigger] a.push(x)[i] >= bound,
{ #[verifier::proof_note("parallel")] assume(false); }
}
```

### PP2 — two occurrences yield matching indices
**Isolates:** `quantifiers`, `requires-ensures`.

Extract justified positions in the two sequences and establish the stated
relationship. A guessed number without its bounds is not an existential proof.

```dafny
module R04_ParallelCommon {
  lemma CommonIndices(a: seq<int>,b: seq<int>,x: int)
    requires x in a && x in b
    ensures exists i,j :: 0 <= i < |a| && 0 <= j < |b| && a[i] == b[j]
}
```

```rust
use vstd::prelude::*;
verus! {
proof fn lemma_common_indices(a: Seq<int>,b: Seq<int>,x: int)
    requires a.contains(x),b.contains(x),
    ensures exists|i: int,j: int| 0 <= i < a.len() && 0 <= j < b.len() && a[i] == b[j],
{ #[verifier::proof_note("parallel")] assume(false); }
}
```
