\section*{B1 (hand-calculation)}

\textbf{(a) The trace.}
\begin{enumerate}
\item The conditional (rule: one-armed conditional, one implication per
  branch): $\mathit{wp}(\texttt{if } y > 10 \texttt{ then } y := y - 10, Q)
  \equiv (y > 10 \Rightarrow \mathit{wp}(y := y - 10, Q)) \wedge (\neg (y > 10)
  \Rightarrow Q)$.
\item Inside it, the assignment (rule: substitute $y - 10$ for $y$ in $Q$):
  $\mathit{wp}(y := y - 10, y < 5) \equiv y - 10 < 5$. So the conditional's
  precondition is $(y > 10 \Rightarrow y - 10 < 5) \wedge (y \le 10
  \Rightarrow y < 5)$.
\item The sequence (rule: $\mathit{wp}(c_1; c_2, Q) \equiv
  \mathit{wp}(c_1, \mathit{wp}(c_2, Q))$), and the first assignment
  (substitute $x + 3$ for $y$): $(x + 3 > 10 \Rightarrow x + 3 - 10 < 5)
  \wedge (x + 3 \le 10 \Rightarrow x + 3 < 5)$.
\end{enumerate}
\textbf{Simplified.} $x + 3 > 10 \iff x > 7$ and $x - 7 < 5 \iff x < 12$;
$x + 3 \le 10 \iff x \le 7$ and $x + 3 < 5 \iff x < 2$. So
$(x > 7 \Rightarrow x < 12) \wedge (x \le 7 \Rightarrow x < 2)$, which is
$x < 2 \vee (7 < x \wedge x < 12)$ (split on $x \le 7$: the first case gives
$x < 2$, the second $7 < x < 12$).

\textbf{(b)} For example $x = 1$: $y = 4$, the condition is false, $4 < 5$:
$Q$ holds. $x = 5$: $y = 8$, the condition is false, $8 < 5$ is false: $Q$
fails, and $5$ is outside the formula. (Also $x = 9$: $y = 12$, then $2$:
holds; $x = 12$: $y = 15$, then $5$: fails.) Any pair with the right
verdicts is correct.

\textbf{(c)} $x \le 1$ or $8 \le x \le 11$, that is $(-\infty, 2) \cup (7,
12)$ over the integers.
