\begin{problem}[concept]\label{prob:B1}
\textbf{Loop measures} (5 minutes). Each loop below is a whole file, run with
\texttt{scripts/vcheck --module Q10}. None has a \texttt{decreases} clause.
\begin{dafnycode}
module A {
  method Up(s: seq<nat>) returns (i: nat)
    ensures i == |s|
  {
    i := 0;
    while i < |s|
    {
      i := i + 1;
    }
  }
}
\end{dafnycode}
\begin{dafnycode}
module B {
  method Down(n: nat) returns (j: nat)
    ensures j == 0
  {
    j := n;
    while j > 0
    {
      j := j - 1;
    }
  }
}
\end{dafnycode}
\begin{dafnycode}
module C {
  method Evens(n: nat) returns (i: nat)
    ensures i == n
  {
    i := 0;
    while i != n
      invariant i <= n
    {
      i := i + 2;
    }
  }
}
\end{dafnycode}
\begin{veruscode}
use vstd::prelude::*;

verus! {

fn up(v: &Vec<u64>) -> (i: usize)
    ensures
        i == v.len(),
{
    let mut i: usize = 0;
    while i < v.len()
        invariant
            i <= v.len(),
    {
        i = i + 1;
    }
    i
}

} // verus!
\end{veruscode}
For each of A, B, C and D (the Verus file): \textbf{(a)} does it verify?
If not, at which stage does it stop (\texttt{parse}, \texttt{resolve} or
verification), and which obligation fails? \textbf{(b)} In one line, why. For
the Dafny loops, say what measure Dafny uses when none is written, and whether
that measure is the loop's problem.
\end{problem}
